# 교회 홈페이지 및 관리자 페이지 구성 명세

이 문서는 교회 홈페이지, 교회별 관리자, 플랫폼 본사 관리자의 화면 구성과 주요 기능을 정의한다.

## 1. 사용자와 권한

| 구분 | 주요 권한 |
|---|---|
| 방문자 | 공개 홈페이지, 게시물, 행사, 공개 초대장 열람 |
| 교회 회원 | 회원 전용 자료, 행사 신청, 마이페이지 |
| 콘텐츠 담당자 | 지정된 게시판·앨범·부서 콘텐츠 관리 |
| 교회 관리자 | 자기 교회의 홈페이지·회원·파일·통계 관리 |
| 교회 대표 관리자 | 관리자 권한·도메인·구독 관리 |
| 플랫폼 운영자 | 전체 교회·구독·서버·사용량·고객지원 관리 |
| 플랫폼 최고관리자 | 운영자 권한·정책·보안·감사 관리 |

모든 업무 데이터는 `church_id`로 격리하며 교회 관리자는 자기 교회 데이터만 조회·수정한다.

## 2. 교회 홈페이지

교회마다 메뉴명, 순서, 공개 범위와 사용 여부를 변경할 수 있다.

### 2.1 홈

- 로고·교회명·주 메뉴
- 메인 이미지 또는 영상 배너
- 예배시간·오시는 길 바로가기
- 담임목사 메시지 또는 오늘의 말씀
- 최신 설교·소식·주보·행사·초대장
- 주소·연락처·SNS·정책 링크
- 섹션별 표시 여부·순서·예약 노출
- 로고 왼쪽형·중앙형 등 헤더 레이아웃 선택

### 2.2 교회소개

- 인사말, 비전·핵심가치, 교회 연혁
- 섬기는 사람들, 예배 안내, 시설 안내
- 오시는 길, 지도, 교통·주차 안내
- 교역자 프로필·순서와 예배별 시간·장소·대상 관리

### 2.3 말씀·예배

- 설교 영상·음성·원고, 생중계, 주보, 찬양
- 설교자·성경본문·시리즈·예배 종류별 검색
- 외부 영상 연결 또는 파일 업로드
- 썸네일, PDF 다운로드, 공개·회원 전용 설정

### 2.4 교회소식

- 공지사항, 교회소식, 행사 일정, 교회앨범, 새가족 소식
- 목록형·카드형·갤러리형 게시판
- 고정글·비밀글·댓글·첨부파일·예약 게시
- 월간 일정과 사진 다중 업로드

### 2.5 공동체·사역

- 부서 소개, 교구·소그룹, 다음세대
- 선교·봉사, 양육·훈련
- 부서별 담당자·게시판·앨범·일정·신청서 연결
- 메뉴별 공개·회원 전용 설정

### 2.6 행사·신청

- 진행 중인 행사, 행사 일정, 참가 신청, 신청 확인
- 예배·부흥회·수련회·세미나·바자회·결혼식·장례 등 유형
- 접수 기간·정원·대기자·참가비·질문 항목
- 신청 명단 내보내기와 행사별 초대장 연결

### 2.7 모바일 초대장

- 한 교회에서 여러 초대장 생성·복제
- 초대 문구, 행사 정보, 이미지·영상·갤러리
- 지도·길찾기·일정 추가·전화·공유
- 참석 여부 또는 참가 신청
- 행사 유형별 템플릿·색상·글꼴
- 공개·비밀번호·비공개·만료 설정
- 초대장별 조회·유입·공유·신청 통계

### 2.8 회원 서비스

- 로그인, 회원가입, 계정 찾기, 마이페이지
- 내 신청 내역과 회원 전용 자료실
- 이메일·휴대전화 인증과 자동·관리자 승인
- 개인정보·비밀번호·수신 동의·탈퇴 요청 관리

### 2.9 기타 필수 페이지

- 온라인 헌금 안내 및 외부 결제 연결
- 통합검색, 문의하기
- 개인정보처리방침, 이용약관
- 이메일 무단수집 거부, 오류·점검 안내

## 3. 교회 관리자

### 3.1 대시보드

- 오늘·월간 방문자와 페이지뷰
- 월 트래픽 사용량 / 구독 한도 / 예상 소진율
- 저장공간 사용량 / 한도 / 파일 종류별 사용량
- 초대장·행사·신청·게시물·문의·가입 승인 현황
- 구독 상태와 다음 결제일
- 트래픽·용량 70%, 85%, 100% 단계 경고

### 3.2 홈페이지 관리

- 기본정보, 도메인·SSL, 디자인·레이아웃
- 메뉴, 메인화면, 페이지, 팝업·배너, SEO
- 메뉴 추가·삭제·정렬·공개 권한
- 템플릿·색상·글꼴, 반응형 미리보기
- 사용자 정의 페이지, 변경 이력, 이전 버전 복원

### 3.3 게시판 관리

- 게시판 생성·복사·보관과 유형 선택
- 읽기·쓰기·댓글·다운로드 권한
- 카테고리·필수 항목·담당자 지정
- 글 일괄 이동·삭제·공개 변경
- 신고·금칙어·스팸·휴지통·복원

### 3.4 파일·사진 관리

- 폴더·검색·정렬·이동·삭제·휴지통
- 업로더·업로드일·연결 게시물·미사용 파일
- 허용 확장자와 파일당 최대 크기
- 앨범·태그·다중 업로드·대표사진
- 썸네일·WebP 자동 생성과 중복 파일 탐지
- 전체/이미지/영상/문서/백업/휴지통별 용량
- 최근 증가량, 예상 소진일, 대용량 파일 정리 제안

### 3.5 초대장 관리

- 목록·생성·복제·미리보기·게시·종료
- 템플릿·행사 정보·갤러리·지도·신청서 편집
- 사용자 지정 주소·공개 범위·만료일
- 방문·공유·신청 통계
- 요금제별 활성 수와 월 신규 생성 수 제한

### 3.6 행사·신청 관리

- 행사 생성과 초대장·게시물 연결
- 접수 기간·정원·대기자·질문 항목
- 신청자 승인·취소·출석·명단 내보내기
- 보유 기간 경과 개인정보 자동 파기

### 3.7 회원·권한 관리

- 회원 검색·승인·정지·탈퇴
- 관리자·부서 담당자 초대와 역할별 권한
- 회원 그룹·부서·로그인·작업 기록
- 비밀번호는 열람하지 않고 재설정만 제공
- 대표 관리자 변경 시 추가 본인확인

### 3.8 트래픽 관리

- 월간·일별 사용량과 남은 한도
- 도메인·페이지·파일·초대장·파일 유형별 전송량
- 비정상 급증·봇·대용량 다운로드 탐지
- 70% 안내, 85% 경고, 100% 제한 정책
- 업로드 제한·미디어 제한·임시 증액·요금제 상향
- 웹서버 로그 또는 CDN 전송 바이트를 교회별 집계

한도 도달 시 전체 홈페이지를 즉시 차단하지 않고 관리자 경고 → 대용량 업로드 제한 → 다운로드·미디어 제한 → 운영자 확인 순서로 처리한다. 예배 안내와 긴급 공지는 가능한 유지한다.

### 3.9 통계 관리

- 실시간·일간·주간·월간 방문자와 페이지뷰
- 신규·재방문, 기기, 유입경로, 인기 페이지
- 설교·게시물·다운로드·초대장·신청 전환
- 기간 비교·CSV 내보내기
- IP 익명화와 통계 원본 보유 기간 제한

### 3.10 구독·결제

- 현재 요금제와 트래픽·용량·관리자·초대장 한도
- 다음 결제일·결제 내역·세금계산서
- 요금제 변경과 추가 트래픽·용량 옵션
- 미납·정지·해지와 데이터 보관 종료일

### 3.11 고객지원·추가기능

- 문의, 오류 신고, 기능 요청, 진행 상태
- 공지·점검 일정·사용 설명서
- 추가기능 견적 요청

추가기능은 교회별 코어 수정 대신 기능 모듈 또는 교회별 설정으로 제공한다. 공통성이 높은 기능은 표준 모듈로 전환하고 전용 기능은 계약·버전·유지보수 범위를 기록한다.

## 4. 플랫폼 본사 관리자

### 4.1 운영 대시보드

- 전체·활성·체험·미납·정지 교회 수
- 서버별 교회 수와 CPU·RAM·디스크·트래픽
- 장애·보안·한도 경고
- 월 구독 매출·미납·지원 요청

### 4.2 교회 관리

- 교회 등록·승인·수정·정지·해지
- 대표 관리자 지정과 초기 초대
- 도메인·요금제·배정 서버·상태 검색
- 기능 활성화와 예외 한도 설정
- 데이터 이전·내보내기·삭제 요청
- 지원 접근 시 사유·시간 제한·감사 기록

### 4.3 서버·배치 관리

- 메인 서버와 교회 데이터 서버 등록
- 서버별 교회·DB·디스크·트래픽·상태
- 서버당 기본 20개 교회 배치와 신규 서버 알림
- 신규 교회 자동 배정, 교회 이전, 점검 모드
- 헬스체크·백업·설치 버전·배포 이력
- 추후 PHP·MariaDB·웹서버·앱·모니터링 자동 설치

20개 도달 여부뿐 아니라 CPU, RAM, 디스크 I/O, 저장공간, 피크 트래픽을 함께 확인한다.

### 4.4 요금제·구독 정책

- 요금제와 버전 관리
- 트래픽·저장공간·관리자·게시판·초대장·기능 한도
- 월·연 결제, 할인, 체험, 맞춤 계약
- 기존 계약 유지 여부와 초과 사용 정책

### 4.5 사용량 통합 관리

- 전체·서버·교회별 트래픽과 용량 순위
- 급증 탐지, 임시·영구 증액, 제한 해제
- 캐시 적중률·대용량 다운로드·이미지 최적화 분석
- 할당량과 실제 물리 디스크 여유 비교
- 집계 재계산 및 관리자 조정 이력

### 4.6 파일 안전·템플릿·기능 모듈

- 악성 파일 검사와 금지 확장자·MIME 정책
- 대용량·중복·미사용 파일 검색
- 홈페이지·초대장 템플릿의 버전·배포·롤백
- 기능 모듈·요금제 연결과 전용 개발 유지보수

### 4.7 통계·매출·보안

- 교회 증가·이탈·활성화와 요금제별 매출·미납
- 서버당·교회당 비용과 자원 원가
- MFA·접근 IP·역할·로그인·작업 감사
- API 키 수명주기와 백업·복구 기록

### 4.8 고객지원·기능 요청

- 문의 담당자·우선순위·상태와 오류 로그 연결
- 공통 기능·유료 모듈·전용 개발 분류
- 견적·승인·개발·검수·배포·유지보수 기록

## 5. 구독제 제한 기준

| 항목 | 기준 |
|---|---|
| 월 트래픽 | 교회별 전송 바이트 합계, 매월 초기화 |
| 저장공간 | 원본·파생 이미지·첨부·휴지통 포함 정책 명시 |
| 관리자 | 활성 관리자 계정 수 |
| 게시판 | 활성 게시판 수 |
| 초대장 | 활성 수와 월 신규 생성 수 각각 제한 |
| 사용자 페이지 | 게시 상태 페이지 수 |
| 파일 크기 | 파일 1개당 최대 크기 |
| 통계 보관 | 3개월·12개월·장기 등 차등 |
| 기능 모듈 | 신청·알림·고급 통계·도메인 등 차등 |

초기 권장 월 트래픽은 30일 체험 2GB, 기본형 6GB, 성장형 20GB, 프리미엄 60GB로 한다. 정확한 제공량은 1~3개월 실사용량 측정 후 확정한다.

## 6. 권장 DB 영역

- `plans`, `plan_versions`, `plan_limits`: 요금제와 한도
- `subscriptions`, `subscription_addons`, `billing_events`: 구독과 부가 옵션
- `church_quotas`, `quota_overrides`: 적용 한도와 예외
- `traffic_daily`, `traffic_monthly`: 트래픽 집계
- `storage_objects`, `storage_usage_daily`: 파일과 저장공간
- `media_albums`, `media_items`, `media_variants`: 사진·영상·썸네일
- `boards`, `board_categories`, `posts`, `comments`, `attachments`: 게시판
- `invitations`, `invitation_sections`, `invitation_guests`: 다중 초대장
- `events`, `event_forms`, `event_applications`: 행사와 신청
- `features`, `plan_features`, `church_features`: 기능 모듈
- `servers`, `server_churches`, `server_metrics`: 서버와 교회 배치
- `admin_audit_logs`, `login_logs`: 감사와 로그인 기록
- `support_tickets`, `feature_requests`: 문의와 기능 요청

파일 본문은 MariaDB가 아닌 파일시스템 또는 객체 저장소에 둔다. DB에는 경로·크기·해시·MIME·소유 교회·연결 대상·삭제 상태를 기록한다.

## 7. 개발 우선순위

1. 교회 생성·로그인·권한·`church_id` 격리
2. 홈페이지 기본정보·메뉴·페이지·디자인
