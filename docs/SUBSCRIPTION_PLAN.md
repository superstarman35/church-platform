# 구독제 및 무료체험 운영안

## 공통 정책

- 모든 영상은 서버 업로드 없이 YouTube 링크 또는 임베드로 제공한다.
- 홈페이지 이미지는 파일당 최대 1MB, 초대장 이미지는 최대 500KB를 권장한다.
- 이미지는 WebP와 화면 크기별 파생 이미지로 자동 변환한다.
- 트래픽은 매월 1일 자동 초기화하고 과거 사용량은 통계로 보존한다.
- 유료 교회만 교회 서버의 20개 배정 기준에 포함한다.
- 30일 체험 계정은 공용 체험 DB에서 `church_id`로 분리하고 결제 후 유료 서버의 교회 DB로 이전한다.

## 30일 무료체험

- 임시 서브도메인과 HTTPS 제공
- 기본 홈페이지, 게시판, 모바일 초대장, 기본 통계 제공
- 개인 도메인·문자·알림톡·고급 통계·수동 트래픽 초기화는 제공하지 않는다.
- 만료 7일 전부터 전환을 안내한다.
- 종료 후 7일 동안 결제·복구할 수 있고 방문자에게 종료 안내를 표시한다.
- 종료 후 30일 동안 데이터를 보관한 뒤 삭제 대기로 전환한다.

## 기본형

- 소규모 교회의 소개·공지·주보·앨범 중심 운영
- 개인 도메인 1개, 기본 백업과 온라인 문의 지원
- 트래픽 추가 구매 또는 상위 상품 변경 가능

## 성장형

- 여러 부서와 정기 행사를 운영하는 교회의 주력 상품
- 전체 디자인, 부서별 담당자, 신청자 내보내기, 상세 통계
- 운영자 승인 방식의 임시 트래픽 지급과 추가 구매 지원

## 프리미엄

- 여러 관리자와 많은 콘텐츠·행사를 운영하는 교회 대상
- 고급 권한·통계·백업·우선지원
- 관리자 화면에서 초기화 또는 증액을 요청하고 운영자가 승인

## 트래픽 알림과 제한

| 사용률 | 처리 |
|---:|---|
| 70% | 교회 관리자에게 안내 |
| 85% | 경고와 추가 구매·상향 안내 |
| 100% | 신규 대용량 업로드 우선 제한 |
| 지속 초과 | 다운로드·고용량 미디어 제한 후 운영자 확인 |

예배시간·주소·전화·긴급공지 등 핵심 정적 페이지는 가능한 계속 제공한다.

교회 관리자는 사용량·다음 초기화일·이력을 확인하고 초기화 또는 증액을 요청한다. 임의 초기화는 허용하지 않는다. 실제 처리는 구독 권한과 플랫폼 운영자 승인에 따라 수행하며 작업자·사유·이전 값·변경 값을 감사 로그에 기록한다.

## 권장 부가 옵션

- 트래픽 5GB 또는 10GB 추가
- 저장공간 500MB 또는 1GB 추가
- 관리자 계정 추가
- 초대장 생성 수 추가
- 행사 신청자 한도 추가

부가 옵션 합계가 상위 요금제와 비슷하면 상위 상품이 더 경제적임을 안내한다.

## 운영 검증

초기 20개 유료 교회의 실제 트래픽, 저장공간, CPU, RAM, 디스크 I/O와 고객지원 시간을 1~3개월 측정한다. 결과에 따라 한도와 가격을 조정하되 기존 고객 정책과 신규 고객 정책을 버전으로 구분한다.
